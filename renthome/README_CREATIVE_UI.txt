StayFinder Creative UI v3

This version keeps the existing PHP/MySQL functionality and adds a warmer modern visual style: custom StayFinder SVG logo, blue-to-violet gradients, Plus Jakarta Sans headings, DM Sans body text, improved cards, hero, buttons, admin sidebar, and form focus states.

Install by replacing C:\xampp\htdocs\renthome with this folder. Keep the existing renthome_db database. Hard refresh with Ctrl+F5.
